# EnlightenedC Language Features

This document outlines the features of EnlightenedC. To best understand this language, you should have
a working knowledge of C, as well as an object-oriented language like C++ or Python. There is also
a [guide](https://holyc-lang.com/docs/intro) to introduce you to the main features of HolyC, and then you
can come back here to see the differences.

## A development note

As this compiler is still in active development, this documentation is not always accurate. As implementation progresses and details change, this documentation may drift from what the compiler actually implements. Additionally, some features here are aspirational and document the **intended** behaviour of the compiler, not the actual behaviour of the compiler as it stands.
